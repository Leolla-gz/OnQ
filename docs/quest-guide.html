3納品する

  • 依頼の納品チェストに品物を入れて、閉じるだけ。閉じたときに数えられます
  • 納品チェストにカーソルを合わせると、画面の上に進み具合が出ます
  • 全部そろうと「達成！」と全員に知らされ、依頼は消えます。品物は依頼主がチェストから受け取ります

4自分の依頼を確認・直す

/quest mine自分の依頼の進み具合。編集 取消 ボタン付き
/quest pick 番号納品物の追加・削除（編集画面）
/quest name 番号 名前クエスト名を付ける（何に使うのか）。例: /quest name 3 拠点の壁の材料
/quest memo 番号 メモ納品チェストの場所のメモを付ける。例: /quest memo 3 拠点前　メモを書かずに打つと消える
/quest chest 番号納品チェストを選び直す
/quest cancel 番号依頼を取り消す
/quest info 番号依頼の詳細・残り日数
/quest helpコマンドの一覧

5こんなときは

  • 使用中のチェストを選んだ → 共有するなら同じチェストをもう一度右クリック。やめるなら別のチェストを右クリック
  • 納品チェストが壊された → 依頼主に知らせが届きます。/quest chest 番号 で選び直せば、続きから再開
  • ログインしていない間のこと（達成・受注など）→ 次にログインしたときにまとめて表示
  • 見本のアイテムを持っている → 手に持って /quest create hand 個数 でも依頼できます

6クエストボードを作る

📖
持って右クリック

光る本（持ち歩けるボード）だれでも

  1. 本を1冊、手に持つ
  2. チャットで /quest boarditem → 本が光る本に変わる
  3. 光る本を持って右クリックすると、どこでもクエスト一覧の画面が開く

本は 革1枚＋紙3枚 で作れます。光る本は何冊作っても大丈夫です。

まん中を右クリック

壁のクエストボード（みんなの掲示板）管理者(OP)

  1. 横3×縦3ブロックの壁を作る（例：樫の板材）。前に2ブロックほど空けておく
  2. チャットで /quest board add
  3. 60秒以内に、壁のまん中のブロックの正面を右クリック → 数秒で依頼が壁に浮かんで並ぶ
  • 表示が崩れた・消えた → /quest board refresh
  • ボードをやめる → /quest board remove のあと、そのブロックを右クリック（壊しても自動で解除）

OP でない人は、置きたい場所を管理者に伝えてください。

!きまり

  • 同時に出せる依頼は 1人5件 まで
  • 1件の依頼に 10種類 まで
  • 合計で チェスト1個分（27マス） まで
  • 発注から 14日 で自動的に取り消し
  • 納品チェストに最初から入っていた分は数えない
  • 依頼主が取り出した分は「受け取り済み」。ほかの人が取り出すと進み具合が戻る
  • ラージチェストは左右どちらを選んでも同じチェスト
  • 納品先はチェスト・樽・シュルカーボックスのみ
  • アイテムは種類だけを見ます（耐久やエンチャントは問いません）
