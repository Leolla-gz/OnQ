# クエストボード mod（Fabric / Minecraft Java版 26.3）

## 1. 概要

| 項目 | 内容 |
|---|---|
| 目的 | 欲しい素材をクエストとして張り出し、同じサーバの人に納品してもらう |
| 対応 | Minecraft Java版 **26.3** / Fabric Loader 0.19.5 以上 / Fabric API 0.161.0+26.3 以上 / Java 25 |
| 導入先 | **サーバだけ**（参加者は mod 不要。バニラのクライアントで参加できる）。シングルプレイでも動く |
| 保存先 | `ワールドフォルダ/questboard.json`（例: `サーバフォルダ\world\questboard.json`） |

## 2. 仕様

| 機能 | 動き |
|---|---|
| 発注 | `/quest create` で作成 → 次に右クリックしたチェストが「納品チェスト」になる。アイテムの名前（ID）を覚えていなければ、`/quest pick`（画面から選ぶ）か、見本を手に持って `/quest create hand` |
| アイテム選択画面 | `/quest pick` またはボード画面の [依頼を出す] で開く。分類（クリエイティブモードのタブ）→ アイテム → 個数 の順に選んで [決定]。アイテム名は各自のゲーム言語で表示される |
| 納品物の編集画面 | 発注した直後、または `/quest pick <番号>` で開く。今の納品物が並び、クリックで削除、[アイテムを追加] で追加、[終了]（扉）で閉じる。納品チェストが未設定なら、閉じた後にチェストを右クリックして設定する |
| 納品先のメモ | 納品チェストに「拠点前」のようなメモを付けられる（任意・30文字まで）。座標と一緒に表示される |
| 納品チェストの案内 | 納品チェストに視線（カーソル）を合わせると、画面上部にバーが並び、1行目に「納品チェスト #3 Steve「拠点前」」、2行目以降に納品物ごとの「石炭 3/10（残り 7）」が表示される（最大7行。ゲージは納品率） |
| チェストの共有 | 同じチェストを複数のクエストの納品先にできる（ほかの人のクエストとも共有できる）。使用中のチェストを選ぶと確認が出るので、共有するなら同じチェストをもう一度右クリック（またはチャットの [共有する]）、共有しないなら別のチェストを右クリック |
| 確認 | `/quest list` `/quest info <番号>` `/quest mine`（自分の依頼の進捗）、またはボード画面 |
| 壁のボード | 壁に登録したブロックの前に、依頼の概要（依頼主の顔・名前・納品物と進捗）が6件ずつ浮かんで表示される（7件以上は [◀ 前] [次 ▶] でページ送り）。左クリックで詳細、右クリックで受注 |
| ボード画面 | 依頼主の顔（プレイヤーの頭）・名前・依頼内容・進捗が並ぶ画面。ボードアイテム（光る本）を持って右クリック、ボードに登録したブロックを右クリック、または `/quest open` で開く |
| 受注(ブックマーク) | `/quest accept <番号>`（ボードの[受注]ボタンでも可）。依頼主に通知される。1つのクエストを何人でも受注でき、受注していない人が納品してもよい（受注は「やります」の表明で、納品の条件ではない） |
| 納品 | 納品チェストに品物を入れて、チェストを閉じる。閉じたときに中身を数えて進捗を更新し、依頼主に通知する（1個ずつ入れても通知は閉じたときの1回）。ホッパーなどでの納品は、約30秒ごとの見回りで数える |
| 取り出し | 募集中に納品チェストから品物を取り出したとき、依頼主が取り出した分は「受け取り済み」として残り個数はそのまま。ほかの人（やホッパー）が取り出した分は残り個数が戻る。依頼主とほかの人が同時に開いていた場合は、戻る側として扱う |
| 達成 | 全部そろうと全員に告知され、クエストは一覧から消える。品物はそのチェストに残るので依頼主が回収 |
| 取り消し | `/quest cancel <番号>`（依頼主またはOP）で一覧から消える |
| 自動取り消し | 発注から14日たったクエストは自動で取り消され、依頼主に知らせる。残り日数は `/quest info <番号>` に出る |
| 不在中のお知らせ | 依頼主がオフラインの間に起きたこと（達成・受注・納品チェストの共有・納品チェストが無くなった・自動取り消し）は、次にログインしたときにまとめて表示される（1人20件まで） |
| 納品チェストが壊されたとき | 依頼主に知らせ、納品先を「未設定」に戻す。そこまでの納品数は残るので、`/quest chest <番号>` で設定し直せば続きから再開できる。壊れたチェストの中身はその場に落ちる |

- 1人が同時に出せるクエストは5件まで、1クエストの納品物は10種類まで
- 1クエストの納品物は、全部でスモールチェスト1個（27マス）に収まる個数まで。64個重ねられる物なら最大1728個、16個までの物（エンダーパール等）は432個、重ねられない物（剣等）は27個。入りきらない個数は登録できない（タグは64個重ねられる物として数える）
- 「木材なら何でも」のようにしたいときはタグを使う（例: `minecraft:logs` = 原木全種、`minecraft:planks` = 板材全種）
- 納品チェストにできるのは、チェスト（ラージチェスト・トラップチェスト・銅のチェストを含む）・樽・シュルカーボックス。かまど・ホッパー・ディスペンサーなどは不可
- ラージチェストは左右どちらを登録しても同じチェストとして扱う（左右を別々のクエストの納品先にすると、共有になる）。クエストの途中でチェストをラージチェストにしても、ラージチェストの片側を壊しても、残っているチェストで続行する
- 他人のクエストが使っている納品チェストを共有すると、先に使っていた依頼主に通知される
- ボードにしたブロックが壊されると、ボードの登録は自動で解除される
- 編集画面を閉じたときに納品物が0種類なら、依頼を取り消すかを聞く
- 名前を変えたプレイヤーがログインすると、その人の依頼の依頼主名が新しい名前になる（受注者の一覧は古い名前のまま）
- クエスト番号は通し番号で、達成・取り消しで空いた番号は再利用しない。`/quest resetid`（OP）で振り直せる（掲示中のクエストが無ければ 1 に戻る）
- 共有チェストで複数のクエストが同じアイテムを募集しているときは、番号の若いクエストから先に数える（1個のアイテムを二重には数えない）
- ほかの人のクエストと共有しているチェストから依頼主が品物を取り出すと、「受け取り済み」になるのは自分のクエストに数えられていた分だけ。ほかの人のクエストに数えられていた分は、そのクエストの残り個数が戻る
- 共有チェストでクエストが達成されると、その品物は依頼主が取り出すまで「取り置き」になり、残りのクエストの納品には数えない

## 3. コマンド一覧

| コマンド | 説明 | 使える人 |
|---|---|---|
| `/quest` または `/quest help` | ヘルプ表示（ふつうの使い方。OP が実行しても同じ内容） | 全員 |
| `/quest help op` | 管理用コマンドのヘルプ | OP（シングルプレイでは誰でも） |
| `/quest guide` | 使い方の説明ページの URL を表示する（クリックでブラウザが開く）。`/quest help` の先頭にも出る | 全員 |
| `/quest guide set <URL>` / `clear` | 説明ページの URL を設定/解除する（ワールドごとに `questboard.json` に保存） | OP（シングルプレイでは誰でも） |
| `/quest list [<ページ>]` | 掲示中のクエスト一覧（5件ずつ。[前のページ] [次のページ] ボタン付き） | 全員 |
| `/quest info <番号>` | 詳細・納品状況・受注者 | 全員 |
| `/quest mine` | 自分が出した依頼の進捗（達成率）と、受注中の依頼 | 全員 |
| `/quest open` | ボード画面を開く | 全員 |
| `/quest boarditem` | 手に持った本1冊をボードアイテムに変える（OP・シングルプレイは本不要） | 全員 |
| `/quest pick` | アイテムを画面から選んで発注。直後にチェストを右クリック | 全員 |
| `/quest pick <番号>` | 納品物の編集画面を開く（追加・削除。[終了] で閉じる） | 依頼主 |
| `/quest create [<アイテム> <個数> ...]` | 発注（一度に最大4種）。直後にチェストを右クリック | 全員 |
| `/quest create hand [<個数>]` | 手に持っているアイテムで発注（個数を省略すると持っている数） | 全員 |
| `/quest add <番号> <アイテム> <個数>` | 納品物を追加 | 依頼主 |
| `/quest add <番号> hand [<個数>]` | 手に持っているアイテムを納品物に追加 | 依頼主 |
| `/quest addtag <番号> <タグ> <個数>` | タグで納品物を追加 | 依頼主 |
| `/quest remove <番号>` | 納品物の一覧を [削除] ボタン付きで表示。押すとその納品物を取り消す（まちがえて登録したとき用） | 依頼主 |
| `/quest remove <番号> <アイテムID または #タグ>` | 納品物を1つ取り消す（例: `/quest remove 1 minecraft:coal`） | 依頼主 |
| `/quest chest <番号> [<メモ>]` | 納品チェストを選び直す。メモ（例: 拠点前）も一緒に付けられる | 依頼主 |
| `/quest name <番号> [<名前>]` | クエスト名（何に使う物を集めているのか。例: 拠点の壁の材料）を付ける。20文字まで。名前を省略すると消す。ボード・一覧・詳細・納品チェストの案内・達成の告知に【名前】として出る | 依頼主 |
| `/quest memo <番号> [<メモ>]` | 納品チェストのメモを付ける。メモを省略すると消す | 依頼主 |
| `/quest share` | 使用中のチェストを選んだときの確認に「共有する」と答える（チャットの[共有する]ボタンと同じ） | 依頼主 |
| `/quest cancel <番号>` | 取り消し | 依頼主・OP |
| `/quest accept <番号>` | 受注 | 依頼主以外（シングルプレイでは自分も可） |
| `/quest board add` / `remove` | 次に右クリックしたブロックをボードに登録/解除 | OP（シングルプレイでは誰でも） |
| `/quest board list` | ボードの場所一覧 | OP（シングルプレイでは誰でも） |
| `/quest board refresh` | 壁のボードの表示を作り直す | OP（シングルプレイでは誰でも） |
| `/quest board demo <件数>` | 表示確認用の見本クエストを作る（依頼主は架空のプレイヤー。1〜100件） | OP（シングルプレイでは誰でも） |
| `/quest board demo clear` | 見本クエストをすべて消す | OP（シングルプレイでは誰でも） |
| `/quest extend <番号> <日数>` | クエストの期限（自動取り消しまでの日数）を延ばす（1〜365日。何度でも延ばせる）。依頼主に通知される | OP（シングルプレイでは誰でも） |
| `/quest resetid` | クエスト番号を振り直す。掲示中のクエストが無ければ次は #1、あればいちばん大きい番号の次から | OP（シングルプレイでは誰でも） |

### 使用例: 「原木10個と石炭3個」を依頼する

```
/quest create minecraft:coal 3        ← 石炭3個で発注（クエスト #1 ができる）
（空のチェストを右クリック）            ← これが納品チェストになる
/quest addtag 1 minecraft:logs 10     ← 原木（種類問わず）10個を追加
```

特定の原木だけでよければ1行で書けます: `/quest create minecraft:oak_log 10 minecraft:coal 3`

### 使用例: 画面からアイテムを選んで依頼する

```
/quest pick                            ← アイテム選択画面が開く（ボード画面の [依頼を出す] でも同じ）
（分類を選ぶ → アイテムを選ぶ → 個数を決めて [決定]）
（編集画面になる。[アイテムを追加] で別のアイテムを追加、まちがえた品物はクリックで削除）
（[終了] を押す）
（チェストを右クリック）               ← これが納品チェストになる
```
- 後から直すときは `/quest pick 1`（または `/quest mine` の [編集]）で同じ編集画面が開く
- 分類はクリエイティブモードのタブと同じ（建築ブロック・材料など）。スポーンエッグと OP 用のタブは出ない
- ポーション・エンチャントの本のように中身違いがある物は 1 個にまとまっていて、種類を問わない依頼になる
- 個数画面の上3段は、その個数をスモールチェストに入れたときの様子（64個を超えた分は次のマスに並ぶ）
- 個数は、スモールチェスト 1 個に収まる数まで（64個重ねられる物なら 1〜1728 個）

### 使用例: アイテムの名前を覚えていないとき（見本がある場合）

```
（欲しいアイテムの見本を1個、手に持つ）
/quest create hand 32                 ← 手に持っているアイテム32個で発注
（チェストを右クリック）
/quest memo 1 拠点前の樽              ← 納品先にメモを付ける（任意）
（別のアイテムを手に持つ）
/quest add 1 hand 16                  ← そのアイテム16個を追加
```

### 使用例: 依頼がたくさんあるときの表示を確認する（OP）

1人が出せるクエストは5件までなので、見本のクエストで確認します。

```
/quest board demo 60                  ← 架空のプレイヤーの依頼を60件作る
/quest open                           ← ボード画面（45件/ページ）と壁のボードで見え方を確認
/quest board demo clear               ← 見本をすべて消す
```
- 見本は納品チェストが無いので達成されない。受注や詳細表示は普通のクエストと同じように試せる

### 使用例: 壁にクエストボードを置く（OP）

```
（横3×縦3ブロックの壁を作る。例: 樫の板材。前に2ブロックほど空間をあける）
/quest board add
（壁の「中央のブロック」の正面を右クリック）
```
数秒後、壁の前に次のような表示が浮かびます。

```
        クエストボード
  掲示中 N 件  右クリック: 受注 / 左クリック: 詳細
  [顔]          [顔]          [顔]
  #1 Steve      #2 Alex       #3 ...
  石炭 3/3      原木 5/10
  [顔]          [顔]          [顔]      ← 4〜6件目
```
- 依頼の表示を**左クリック**: 詳細をチャットに表示 / **右クリック**: 受注
- 7件以上あるときは、タイトルの左右に [◀ 前] [次 ▶] が出る。クリック（左右どちらでも）でページが変わる。ページは全員共通で、30秒ほど誰も操作しないと1ページ目に戻る
- 文字も顔も壁と平行に固定されていて、見る人が動いても向きは変わらない。進捗は、納品チェストが閉じられたとき（と約30秒ごとの見回り）に数えた結果が約2秒以内に反映される
- 壁のブロック自体を右クリックすると、全件のボード画面が開く（Shiftを押しながらだと通常の操作）
- 表示が崩れた・消えたときは `/quest board refresh`
- 表示はバニラのエンティティ（text_display / interaction）なので、参加者は mod 不要

### ボード画面の見方

```
┌───────────────────────────────┐
│ [顔][顔][顔] …  依頼書（最大45件/ページ）        │  ← 依頼主の頭。名前「#3 Steve の依頼」
│                                               │     説明文に納品物・進捗・納品先・受注者
│ [自分の依頼][依頼を出す] ─ [前へ][案内][次へ] ─ ─ │
└───────────────────────────────┘
```
- 依頼書を左クリック: 受注 / 右クリック: 画面を閉じて詳細をチャットに表示
- [自分の依頼]: 画面を閉じて `/quest mine` と同じ内容を表示
- [依頼を出す]: アイテム選択画面を開く（`/quest pick` と同じ）
- 画面のアイテムは表示用なので取り出せない

## 4. ビルド手順（Windows の場合）

C言語でいう「make して実行ファイルを作る」作業です。`gradlew.bat` がビルドツール（Gradle）を自動で用意し、Minecraft 本体や Fabric を自動でダウンロードしてコンパイルします。

### 4-1. Java 25 (JDK) を入れる（初回のみ）

1. https://adoptium.net/ から **Temurin 25 (LTS)** の Windows 用 `.msi` をダウンロードしてインストール
   - 途中の「Set JAVA_HOME variable」を有効にする（ビルドツールが Java の場所を見つけるための環境変数）
2. 確認: スタートメニューで「PowerShell」を開き、次を実行
   ```powershell
   java -version
   ```
   - 意味: インストールされている Java のバージョンを表示する
   - `openjdk version "25...."` と出ればOK

### 4-2. ソースを置く

このフォルダ（`questboard`）を丸ごと、例えば `C:\mods\questboard` にコピーします。
（日本語や空白を含むパスは避けると安全です）

### 4-3. ビルドする

1. エクスプローラーで `C:\mods\questboard` を開く
2. アドレスバーに `powershell` と入力して Enter（そのフォルダで PowerShell が開く）
3. 次を実行
   ```powershell
   .\gradlew.bat build
   ```
   - 意味: このフォルダのプロジェクトをコンパイルし、mod の jar ファイルを作る
   - 初回は Gradle・Minecraft・Fabric のダウンロードで数分〜十数分かかる
   - 最後に `BUILD SUCCESSFUL` と出れば成功
4. 出来上がり: `C:\mods\questboard\build\libs\questboard-1.1.0.jar`
   - 同じ場所に `-sources` 付きのファイルがあればそれは使わない

## 5. サーバへの導入手順

1. Fabric サーバを用意する（まだの場合）
   - https://fabricmc.net/use/server/ で Minecraft `26.3`、Loader `0.19.5` 以上を選び、サーバ起動用 jar をダウンロード
2. Fabric API を入れる
   - https://modrinth.com/mod/fabric-api から **26.3 用**（0.161.0+26.3 以上）をダウンロード
3. サーバフォルダの `mods` フォルダに次の2つを置く
   - `fabric-api-0.161.0+26.3.jar`（またはそれ以降）
   - `questboard-1.1.0.jar`
4. サーバを起動し、ログに `クエストボードを読み込みました` と出れば導入完了
5. 参加者は何も入れなくてよい（通常のバニラ 26.3 クライアントで参加可能）

### 一人で試したいとき（シングルプレイ）

1. https://fabricmc.net/use/installer/ から Fabric インストーラ（`.exe`）をダウンロードして実行
   - 「クライアント」タブで Minecraft `26.3` を選び「インストール」
2. エクスプローラーのアドレスバーに `%APPDATA%\.minecraft\mods` と入力して Enter（無ければ `mods` フォルダを作る）
3. そこに `fabric-api-0.161.0+26.3.jar`（またはそれ以降） と `questboard-1.1.0.jar` を置く
4. 公式ランチャーで起動構成「fabric-loader-26.3」を選んで起動し、新しいワールドを作る
5. 試す流れ（チート無効でも全コマンドを使える）
   ```
   /quest boarditem                     ← ボードアイテム（光る本）をもらう
   /quest create minecraft:coal 3       ← 発注 → 置いたチェストを右クリック
   （光る本を持って右クリック）         ← 自分の顔の依頼書が並ぶ
   （依頼書を左クリック）               ← 受注（シングルプレイでは自分の依頼も受注可）
   （チェストに石炭を3個入れる）         ← 約1秒で達成の告知
   /quest mine                          ← 途中の進捗確認
   ```

シングルプレイ（とLAN公開ワールド）では、動作確認しやすいよう次の制限を外しています。
専用サーバでは通常どおりです。
- 自分の依頼を受注できる
- ボードの登録・解除と、ボードアイテムの入手（本不要）が誰でもできる

## 7. 既知の制限・注意

- 納品チェストは普通のチェストなので、誰でも中身を取り出せる（取り出すと進捗も戻る）。保護系 mod やワールド保護と併用を推奨
- 納品チェストのあるチャンクが読み込まれていない間は進捗が更新されない（近くに誰かいれば更新される）
- 納品チェストを決めた時点（または納品物を追加した時点）で既に入っていた条件に合うアイテムは、納品数に数えない。その後に入れた分だけを数える
- 納品チェストのあるチャンクが読み込まれていない間は、チェストが壊されたことにも気づかない（読み込まれた時点で気づく）
- 誰が何個納品したかは記録しない
- 依頼主の顔は、プレイヤー名から Mojang のスキン情報を引いて表示する。オフラインモードのサーバや通信できない環境では、標準スキンの顔になる
- 壁のボードの表示用エンティティは、`/kill @e` などで消すと次の内容変化まで出ない（`/quest board refresh` で戻る）
- ボード画面は開いた時点の内容。進捗の変化はクリック操作か開き直しで反映される
- Minecraft のバージョンを変えるときは `gradle.properties` と `fabric.mod.json` のバージョンを https://fabricmc.net/develop の値に合わせる。26.x 系は Java 25 と別のビルド設定が必要
